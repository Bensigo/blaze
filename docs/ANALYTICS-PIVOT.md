# Analytics pivot

Blaze now targets web-game analytics, SEO and AEO, with an MIT license and read-only MCP access for external agents. This supersedes its earlier marketing/content-production scope.

Removed executable AI provider, generated-content, automated gameplay, social publishing, calendar and worker paths, plus their packages, settings and obsolete documentation. Retained authentication, workspace isolation, SDK collection, synthetic exclusion, analytics, consented private player capture, capture retention cleanup, game administration, diagnostics and release measurements. Legacy database records are preserved without re-enabling their old execution paths.

Discovery provides safe static-page audits and dated Search Console Web observations. Bing AI Performance evidence is owner-reported and explicitly unverified; this is not automated universal citation tracking. Page readiness and actual visibility remain separate.

MCP tools list games and read aggregate analytics or cached SEO/AEO/citation evidence. Tokens are workspace-bound, hashed, revocable and expire after 90 days. No settings, scans, raw identifiers or private recordings are exposed.

The existing repository remains private. Historical internal documents and screenshots remain in its Git history; use a reviewed fresh source snapshot for public publication rather than changing that history's visibility without review. No production database deletion or production deployment accompanies this branch.

See README.md, PRD.md, CONTEXT.md, MCP.md and SEO-AEO.md for the current setup and behavior. Verification and remaining live-account limits are recorded separately for each release.
