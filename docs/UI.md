# Workspace UI

Visual thesis: a quiet, warm workspace that puts player evidence and real game media before decoration.

The interface uses a dark navigation rail, a restrained violet action color and divided working surfaces. The overview, analytics and session inspector expose measured human activity; recordings, clips, content and calendar carry that evidence into a reviewable publishing workflow. Setup and connection states remain visible. Example data is labeled throughout and mutations are disabled.

Navigation, dialogs and loading states use short transitions; reduced-motion preferences remove them. Wide layouts make room for context beside the working surface, while mobile navigation becomes a drawer and tables remain horizontally scrollable.

Authenticated workspace data refreshes every five seconds while recording, clip or publishing work is in progress and every 30 seconds while idle. It also refreshes when the tab becomes visible or when the operator selects Refresh. The selected recording and clip inspectors follow updated job status; in-progress form edits are not replaced. The example workspace remains read-only.
