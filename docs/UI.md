# Workspace UI

Blaze uses light neutral surfaces, strong ink text, readable charts, actual game artwork and one restrained green accent. Navigation groups player evidence (dashboard, games, analytics, sessions and optional Forever diagnostics) and insights (SEO/AEO and tracked findings/measurements). Connections are Search Console only; Account manages read-only agent access.

Preserve explicit empty, unavailable, fixture and read-only demo states. The example workspace must never write records or count as real traffic. Charts distinguish missing coverage from zero activity, elapsed session span from measured active play, and immature cohorts from returned players.

Session capture requires owner configuration, reviewed canvas surface and separate affirmative player consent. Capture remains private and bounded; timeline playback and heatmaps are investigation aids, not semantic game understanding.

Discovery shows dated static-page checks, actionable fixes, authorized Search Console observations and separate owner-reported citation evidence. No generic AI score or guaranteed outcome. Page checks run on owner request.

External agents use the read-only MCP bridge. Token creation shows the bearer once, wraps long values on phones, reports clipboard errors and allows immediate revocation. Settings and scan triggers are not exposed to agents.

Check the complete workspace at wide, tablet and phone sizes. Keep tables and inspectors usable without page-level overflow. Reduced-motion preferences should suppress decorative transitions.
